Watch Before You Scale

⚠️
Promo Dependency — Test First
50% of top active orders used a promo code. Scaling a loyalty program on top of discount-driven behaviour risks training users to never pay full price.
📏
80 Rows = Direction, Not Decision
All findings are directional. Statistical significance requires 6–12 months of production data. Use this to form hypotheses, not commit budgets.
📅
Can't Detect Churn Yet
90-day window is too compressed to distinguish lapsed users from churned ones. Recency scoring requires a longer observation horizon.

Live Query Demo

Ask the Data Directly

One natural-language question → SQL generated by Claude → results pulled from MySQL via MCP. No BI tool. No engineering queue.

SQL Generated by Claude
SELECT
  user_id,
  COUNT(*)                        AS order_count,
  ROUND(AVG(order_total), 2)      AS avg_spend,
  ROUND(AVG(rating), 1)           AS avg_rating,
  GROUP_CONCAT(DISTINCT cuisine_type
               ORDER BY cuisine_type
               SEPARATOR ', ')    AS cuisines_ordered
FROM ubereats_mock
GROUP BY user_id
HAVING order_count >= 2
ORDER BY order_count DESC
LIMIT 8;
